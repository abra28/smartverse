OBS / vMix Setup

Method 1: Popup Window + Window Capture (Recommended)

OBS/vMix Browser Source runs in an isolated browser that cannot share data with your main browser. The reliable method is:

  1. Click Output button in top bar
  2. A clean popup window opens
  3. In OBS/vMix, add Window Capture (NOT Browser Source)
  4. Select the "SmartVerse Output" popup window
  5. Crop/Pad to remove window borders if needed

Method 2: Browser Source (Same browser only)

Browser Source Settings:

  • Width: 1920 Height: 1080
  • Custom CSS: body{background:transparent;}
  • Shutdown source when not visible: UNCHECK
  • Refresh browser when scene becomes active: UNCHECK

Quick Help

1. Download Bible: Click Download Full Bible to store all 31,102 verses locally.

2. Connect Mic: Click Connect Mic. Allow browser permission.

3. Listen: Click Listen (or press Space). Speak naturally.

4. Prev/Next: Use << and >> buttons on the verse card to navigate.

5. Output: Click Output button for a clean popup window. Use Window Capture in OBS/vMix.

Hotkeys: Space = Listen/Stop, Esc = Clear, F = Fullscreen, Enter = Search
